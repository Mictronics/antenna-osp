# Switching inputs by touch

Connect one of the six inputs to the output.

## Steps

1. On the main screen, touch the button for the input you want, for example **IN 4**.
2. The relays click and a green frame moves to that button.

## What you should see

Exactly one button has a green frame: the input that is connected now.

## Things to know

- A button reacts when you touch it, not when you release it. Holding your finger on it does nothing more.
- If a computer has set the relays to a combination that is not one of the six inputs, no button has a frame.
- After 1 hour without a touch or a route change from the computer, the device switches back to IN 1 by itself. See [Automatic power saving](power-saving.md).
- While the **REMOTE** screen is shown, the buttons are locked. See [Remote control lock](remote-lock.md).
