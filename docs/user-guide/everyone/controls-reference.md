# Controls and indicators reference

The device has no physical buttons. All operation is by touching the screen.

## Main screen

| Touch area | What happens |
|---|---|
| **IN 1** to **IN 6** | Connects that input to the output; a green frame marks it |
| **Settings** (blue bar) | Opens the Settings screen |

## Settings screen

| Touch area | What happens |
|---|---|
| **25%**, **50%**, **75%**, **100%** | Sets the brightness and saves it |
| **Back** (blue bar) | Returns to the main screen |

## REMOTE screen

| Touch area | What happens |
|---|---|
| Anywhere | Returns to the previous screen |

## Indicators

| What you see | Meaning |
|---|---|
| Splash picture for about 3 seconds | Start-up |
| Green frame on an input | That input is connected |
| No green frame | The relays are in a combination that is no input |
| REMOTE with padlock | A computer is controlling the device |
| Screen completely dark | Backlight off after 5 minutes without a touch; touch to wake |
| Plain grey rectangles without text | The SD card images are missing |
| Battery symbol on the Settings screen | Battery level in 25 % steps |

## Relay and input mapping

| Input | Relays energised |
|---|---|
| IN 1 | none |
| IN 2 | K2 |
| IN 3 | K1 |
| IN 4 | K1, K4 |
| IN 5 | K1, K3 |
| IN 6 | K1, K3, K5 |
